Welcome to Vaelen — connect DeepSeek

Paste one API key and it is saved to ~/.vaelen/config.json for every future session. Takes about a minute.

  1. 1Create an account at platform.deepseek.com → (or log in →).
  2. 2Open API keys →, press Create new API key, copy the sk-… value.
  3. 3Paste it below and press Connect. New keys can take ~30s to activate — if the first turn says invalid key, wait and retry.
